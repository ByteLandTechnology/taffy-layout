# Clear

Controls which preceding floats a box must clear in block layout.

## Enumeration Members

| Enumeration Member                            | Value | Description                          |
| --------------------------------------------- | ----- | ------------------------------------ |
| <a id="enumeration-member-both"></a> `Both`   | `2`   | Clear preceding floats on both sides |
| <a id="enumeration-member-left"></a> `Left`   | `0`   | Clear preceding left floats          |
| <a id="enumeration-member-none"></a> `None`   | `3`   | Do not clear preceding floats        |
| <a id="enumeration-member-right"></a> `Right` | `1`   | Clear preceding right floats         |
