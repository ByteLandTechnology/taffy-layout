# Direction

Writing direction used for logical layout and bidirectional positioning.

## Enumeration Members

| Enumeration Member                        | Value | Description                     |
| ----------------------------------------- | ----- | ------------------------------- |
| <a id="enumeration-member-ltr"></a> `Ltr` | `0`   | Left-to-right writing direction |
| <a id="enumeration-member-rtl"></a> `Rtl` | `1`   | Right-to-left writing direction |
