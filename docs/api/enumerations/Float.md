# Float

Controls whether a box floats to the left or right in block layout.

## Enumeration Members

| Enumeration Member                            | Value | Description                                              |
| --------------------------------------------- | ----- | -------------------------------------------------------- |
| <a id="enumeration-member-left"></a> `Left`   | `0`   | Float to the physical left side of the containing block  |
| <a id="enumeration-member-none"></a> `None`   | `2`   | Do not float                                             |
| <a id="enumeration-member-right"></a> `Right` | `1`   | Float to the physical right side of the containing block |
